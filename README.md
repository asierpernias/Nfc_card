# PCB Business Card

My fully customized business card printed as a real circuit board. The contact info is not only displayed as silkscreen but also with exposed copper. It uses a ST25TN01K NFC chip that, connected to an custom copper coil serves as a nfc tag that links to my github/portfolio.


## BOM

| Ref | Qty | Part |
|---|---|---|
| U1 | 1 | ST25TN01K-AFH5 (NFC Forum Type 2 tag) |

## Contact data displayed

- Email: asier.pernias@gmail.com
- Github:  [github.com/asierpernias](https://github.com/asierpernias)
